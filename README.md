# loophub-test

ブラウザに「Hello World」と表示する Vite + TypeScript のシンプルなウェブアプリです。

## セットアップ

```sh
npm install
```

## 起動

```sh
npm run dev
```

表示された URL（通常は http://localhost:5173 ）をブラウザで開くと「Hello World」が表示されます。

## ビルド

```sh
npm run build
```

型チェック後、`dist/` に成果物が出力されます。`npm run preview` でビルド結果を確認できます。
